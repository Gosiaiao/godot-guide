# Godot 4 系统学习指南

以 **Godot 4.7 Standard** 稳定版为准编写的 Godot 4 系统学习路线指南（4.4 及以上版本基本适用），涵盖从零入门、核心子系统、数据驱动与设计模式、项目架构与工程化，到进阶拓展与免费游戏素材索引。

## 在线阅读

- 网页版（GitHub Pages）：https://gosiaiao.github.io/godot-guide/

## 仓库内容

- `docs/`：静态网页版文档（基于 `godotengine/godot-docs` 主题样式构建，支持深色/浅色主题切换、侧边栏折叠目录、全文搜索与代码一键复制）
- `Godot学习指南.md`：Markdown 源文件
- `Godot学习指南.pdf`：暗色排版 PDF 版本
